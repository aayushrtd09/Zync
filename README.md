# Zync

Zync is a full-stack web application built with React and Node.js, featuring a separate frontend and backend architecture. The application uses REST APIs for client-server communication and Socket.IO for real-time communication.

## 🚀 Tech Stack

### Frontend
- React.js
- React Router
- Material UI (MUI)
- Axios
- Socket.IO Client

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- bcrypt
- CORS
- dotenv
